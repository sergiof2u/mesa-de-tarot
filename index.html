Cómo poner las cartas

La estructura queda fija cuando pones la primera carta en la mesa.

Desliza el mazo, toca una carta para levantarla y tócala otra vez (o usa «Poner esta carta») para llevarla al siguiente lugar de la mesa. Cuando la mesa esté llena, toca cada carta para voltearla.

Una carta más

Para aclarar algo o ver cómo se supera un bloqueo, saca otra carta del mazo que queda.
